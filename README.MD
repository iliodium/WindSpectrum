# Программный модуль расчета нестационарных ветровых нагрузок

## Описание
Программный модуль предназначен для расчета нестационарных ветровых нагрузок и воздействий на несущие, фасадные и кровельные конструкции типовых форм зданий и сооружений. Разработан на языке Python 3.13 и предоставляет удобный инструмент для моделирования ветровых нагрузок.

## Возможности
- Расчет ветровых нагрузок с учетом нестационарных эффектов.
- Анализ воздействия на несущие конструкции.
- Моделирование воздействия на фасадные и кровельные конструкции.
- Гибкая настройка параметров расчетов.

## Установка
### Требования
- Python 3.13
- Необходимые зависимости указаны в `requirements.txt`

### Установка зависимостей
Перед запуском установите все необходимые зависимости, выполнив команду:
```sh
pip install -r requirements.txt
```
